# Contributing

Contributions, research notes, bug reports, and documentation improvements are welcome.

## Bug reports

Please include:

- Game or diagnostic system being tested
- Operating system
- Python version
- Exact steps to reproduce the issue
- Console output or screenshots
- Relevant emulator logs

## Development

Please explain the technical reason behind changes to CPU, DPRAM, MMIO, FIFO, video, or DOSBox emulation code.

## Usage and Attribution

research, preservation, educational, and personal projects.
